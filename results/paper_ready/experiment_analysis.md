# 实验结果分析

## 1. 实验主结果分析

基于 clean run 结果，Sparse-LoRA+GAT 的平均 `Travel Time (s)` 最低，为 503.47；Sparse-LoRA-v2 为 511.15，与前者非常接近；Rule-A* 为 513.55，是一个明显偏强的非学习基线。由此可见，GAT 级联带来的收益存在，但属于条件性收益，而不是在所有场景中都形成大幅优势。

从协议化耗时拆分看，Sparse-LoRA-v2 与 Sparse-LoRA+GAT 的平均 `model_infer_time_s` 分别为 1.47 和 1.48，显著低于 Qwen-LoRA 的 15.86 和 R1-LoRA 的 31.49；对应 `route_solve_time_s` 仅在 `10^-4` 秒量级。因此，当前主证据中的 `Planning Time (s)` 应理解为 `model_infer_time_s + route_solve_time_s`，而不是旧表里的毫秒级纯求解时间。

从约束符合率看，Sparse-LoRA 与 Sparse-LoRA+GAT 均为 68.23%，高于 Rule-A* 的 61.57%。因此，稀疏方案在保持较低推理开销的同时，仍能在约束一致性上保持竞争力。

## 2. 创新点分析

本工作的有效创新点主要体现在两方面。第一，采用稀疏异常边输出，避免让模型在主路网场景下直接生成全量边权，从而显著降低了推理开销。第二，在稀疏输出之后引入图补全/图平滑模块，将局部异常语义扩展到拓扑邻域，使搜索器获得更完整的代价分布。最终，系统形成了“语言路况理解-边权生成-图补全-A*搜索-SUMO闭环验证”的可解释链条。

## 3. 局限性分析

第一，当前真实 SUMO 路网的有向边数为 96，而不是早期文案中的 98；本阶段已在 clean run 结果中统一为 96，但历史材料仍需手工清理。第二，GAT 的收益具有条件性，在部分场景中改善明显，在部分场景中仅持平或微弱退化。第三，SmallNet 中的 Sparse-LoRA+GAT 目前为 skipped，因为现有 GAT 仅适配主路网图，不应将其纳入正式主结论。第四，历史 `true_travel_time` 只应保留为 `analytical_travel_time_s_legacy`，不能再被当作 live SUMO `Travel Time (s)`。

## 4. 失败案例分析

在 Qwen-LoRA 与 LoRA+GAT 的若干复杂场景中，解析器会返回空结果。clean run 中这类情况已统一回退为默认中性权重 2.0，并显式记录 parse_failed_default_2.0，而不再像旧版本那样回退到 1.0。由此，失败不会再被伪装成“高信号覆盖率”，结果解释也更可信。

## 5. 后续工作

后续工作可围绕三个方向展开：其一，训练适配 96 边主路网与 24 边 SmallNet 的统一图补全模型；其二，引入边级置信度建模，使 GAT 仅在低置信边上介入；其三，将当前的离线静态场景评测进一步扩展为在线动态重规划评测，以验证方法在连续时序交通扰动中的稳定性。
