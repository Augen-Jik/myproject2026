## Key Findings

1. Frozen benchmark bindings are explicit and stable in `final_table_loader.py`, but the currently selected exploratory compare artifact is still a legacy run with starred labels and legacy timing fields.
2. The frozen main table CSV still contains a `Sparse-LoRA+GAT` row, and the frozen ablation CSV still uses `LoRA+GAT` / `Sparse-LoRA+GAT` variants. So GAT is not only a display-layer toggle; it still exists in benchmark-facing artifacts.
3. The UI default showcase map stack is still `Labeled Light Basemap + Realistic Block Overlay Map + Real Map (Folium)`.
4. The realistic overlay geometry is built by selecting real road corridors from OSM, computing row/column intersections, and slicing each logical edge polyline between adjacent mapped intersections.
5. Recommended showcase scenes come from `select_demo_scenarios(...)`, which scores OD pairs directly on scene-profile environment weights; it does not depend on the free-text parser.
6. The benefit box uses baseline-vs-planned route time, preferring SUMO actual travel time and falling back to environment-weight estimates if a SUMO route is unavailable.
7. The raw default form is not a runnable positive-gain case because the UI blocks execution when `traffic_constraint` is empty; the guaranteed positive-gain entry currently lives in the recommended demo cases rather than a preselected default case.
