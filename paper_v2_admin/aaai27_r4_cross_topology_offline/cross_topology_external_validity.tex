\subsection{Cross-topology offline grounding quality (external validity)}
\label{app:r4-cross-topology}

To probe whether the offline grounding quality reported on the primary grid
($M1$, $|E|{=}98$) generalizes across road-network topology and scale, we
re-evaluate the canonical STAG adapter on the held-out families already present
in the frozen benchmark: $M2$ (Grid-M, $|E|{=}194$), $M3$ (Grid-L, $|E|{=}398$),
and $M5$ (Irregular, $|E|{=}118$), each with $n{=}100$ oracle-covered instances.
$M4$ (Renamed-grid, $|E|{=}98$) is included only as a label control and is
\emph{not} counted toward cross-topology external validity. This is an offline
re-scoring widen: identical canonical adapter, identical CC6B-1 scorer, and
identical column definitions and frame-free road-level recall convention as the
main offline table (Sec.~\ref{sec:p4}); the aggregation reproduces the main-table
overall numbers exactly on all reported quantities. \emph{anchor\_recall} is the
scorer's road-level (road, type, direction) match, i.e.\ the frame-free road-level
recall; no edge-id frame is reintroduced.

\paragraph{Takeaway.} STAG's \emph{offline} road-level grounding interface is
robust to network topology and scale: across a $4\times$ edge-count range and an
irregular non-grid layout, road identification, schema conformance, hallucination,
temporal and conflict-resolution quality are maintained, with the residual gap
localized to directional disambiguation on irregular geometry. This strengthens
the external validity of the offline grounding claim. It is an offline-quality
result and does not extend the closed-loop evaluation, which remains
single-network (Sec.~\ref{sec:limitations}).
